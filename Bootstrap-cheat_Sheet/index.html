Sample Questions - Bootstrap Framework

Bootstrap Grid System

  • What is the primary purpose of Bootstrap’s grid system?
    Answer: To create a flexible layout structure by dividing the space into rows and columns.
  • How does the Bootstrap grid system differ when using .container vs .container-fluid?
    Answer: .container provides a fixed-width layout that adjusts based on set breakpoints while .container-fluid creates a layout that spans across the entire screen.
  • What is the significance of using .col-md-4 in Bootstrap?
    Answer: Divides the row into 12 equal columns and assigns 4 columns to the element.
  • What breakpoints does Bootstrap’s grid system use for responsive design?
    Answer: xs (<576px), sm (≥576px), md (≥768px), lg (≥992px), xl (≥1200px), and xxl (≥1400px).
  • How do you offset columns in Bootstrap's grid?
    Answer: Use .col-md-x offset-md-wantedOffset.

Bootstrap Components

  • How would you create a responsive navigation bar in Bootstrap?
    Answer: Use the <nav> element + .navbar and additional classes for responsiveness.
  • What class would you use to create a Bootstrap button with a primary style?
    Answer: .btn-primary.
  • Which Bootstrap component can be used to create collapsible content?
    Answer: The Collapse component.
  • What is the purpose of the .card component in Bootstrap, and how do you structure its content?
    Answer: Used to create content headers with consistent looks. Structure includes .card-header, .card-body, etc.

Bootstrap Utilities

  • What class would you use to add margins to an element in Bootstrap?
    Answer: .m-* (Margin size).
  • How can you center text within a Bootstrap element?
    Answer: Use the .text-center class.
  • What Bootstrap utility class can you use to hide an element on small screens but display it on larger screens?
    Answer: .d-none, d-sm-block.
  • How do you make an element float to the right using Bootstrap utility classes?
    Answer: Use .float-end.
  • How can you set the display property of an element to flex using Bootstrap?
    Answer: Use the .d-flex class.

Customizing Bootstrap

  • How can you override the default color scheme in Bootstrap?
    Answer: Using custom CSS or overwriting the SASS values.
  • What is the difference between using Bootstrap via a CDN and downloading the source files?
    Answer: CDN allows for faster loading through shared caching, while downloading source files provides complete control for customization.
  • What are some ways to customize Bootstrap's look without editing its source files directly?
    Answer: Using custom CSS.
  • How can you include custom styles for specific components without affecting the entire Bootstrap theme?
    Answer: Define specific IDs.
  • What role does SASS/SCSS play in customizing Bootstrap’s styles?
    Answer: It is used for editing variables, mixins, and nested rules.

Bootstrap JavaScript Plugins

  • How can you make an element collapse when a button is clicked using Bootstrap's JS components?
    Answer: Use the data-bs-toggle="collapse" attribute on the button and target the collapsible element with data-bs-target.
  • Which Bootstrap plugin is used to create interactive tooltips?
    Answer: Tooltip.
  • How can you trigger a modal to open when a button is clicked?
    Answer: Use the data-bs-toggle="modal" attribute on the button and specify the modal ID in data-bs-target.
  • What is required to enable Bootstrap's JavaScript plugins in a project?
    Answer: Include Bootstrap's JavaScript bundle via a CDN or download it manually.
  • How would you implement a carousel in Bootstrap, and what options are available for customization?
    Answer: Use the .carousel component with .carousel-item for slides and customize using attributes like data-bs-interval.

Bootstrap Best Practices

  • When should you use .container-fluid instead of .container in a layout?
    Answer: When needing a layout whose width spans across the entire screen.
  • Why is it recommended to use Bootstrap classes for styling rather than writing custom CSS from scratch?
    Answer: Bootstrap simplifies the development process with prebuilt and well-documented classes.
  • What are the advantages of using utility classes in Bootstrap?
    Answer: They provide reusable styles without the need for extra CSS.
  • How can you ensure that a Bootstrap site is accessible and complies with accessibility guidelines?
    Answer: Test it across multiple browsers and devices.
  • How do you manage Bootstrap classes when using a front-end framework like React or Angular?
    Answer: Use class bindings or libraries like react-bootstrap or ngx-bootstrap.
